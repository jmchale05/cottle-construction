Stud Walls & Panelling

These photos show examples of our interior work, from building new timber stud walls and blocking up old doorways to finishing rooms with slatted wood panelling.

Stud walls are framed out in timber and fixed securely so they are ready for boarding, and old doorways are framed and boarded in flush with the surrounding wall, ready for plastering.

Slatted panelling adds warmth and character to a room, and it works best when the walls behind it are straight and solid. Whatever the job, getting the framing right first means the finished room looks sharp and lines up properly.

Project Tips

Interior alterations like these are about solid framing and careful finishing. A straight, secure frame makes boarding, plastering and panelling far easier to get right.

  • Build stud walls square, level and securely fixed top and bottom.
  • Plan cables and sockets before the walls are boarded.
  • Frame blocked-up doorways so the infill sits flush with the wall.
  • Leave infills ready for plaster so the join disappears once finished.
  • Fix panelling to a straight base so the slats line up neatly.

Overview & Challenge

Interior alterations like these need solid framing and careful finishing. From new walls and blocked-up doorways through to feature panelling, we make sure each stage is done properly so the finished room looks right and lasts.
